# markdowns/ — der freie Platz

Hier liegen Dokumente, die Claude lesen können soll, die aber **kein
Cockpit-Gedächtnis** sind: Konzepte im Entstehen, Notizen, Vorlagen,
Recherchen, alles, was von überall erreichbar sein muss.

**Die Trennlinie, damit nichts doppelt geführt wird:**

- Gehört es zu Markus' Welt, wächst es und wird versioniert
  (Persona, Stände, Lagen, laufende Projekte, Kontakte)
  → **Cockpit-Ablage**, nicht hierher.
- Ist es Einrichtung, Vorlage oder ein Text, den Claude einfach lesen soll
  → **hierher**.

Im Zweifel: Cockpit. Ein Dokument, das an zwei Orten lebt, ist an beiden falsch.
